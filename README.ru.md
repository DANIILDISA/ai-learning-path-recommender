# Как скачать и запустить

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Распакуйте архив в любую папку (лучше с коротким путём, например `C:\Case\`).
3. Установите Python 3.10+ (если его ещё нет) и дважды щёлкните **START.bat** (macOS/Linux — `./start.sh`). Node.js не нужен — интерфейс уже собран.
   > В публичной версии репозитория вшитое окружение `runtime/` не хранится — оно нужно только для офлайн-поставки заказчику.
4. Обновление: скачайте ZIP заново и замените папку, предварительно сохранив свои данные (загруженные файлы, папку `output/`), если вы их загружали.

# Мой путь развития

ИИ-агент индивидуальной траектории обучения для государственных гражданских
служащих Санкт-Петербурга.

## Что это

Продукт подбирает каждому служащему личную подборку из программ обучения
2025 года — что можно пройти дальше, исходя из должности, уже пройденного
обучения и того, что проходят коллеги на такой же должности. Все программы
**бесплатны**. Задача продукта — заинтересовать пройти обучение, а не
назначить его: каждую программу можно принять, отложить или отметить как
неактуальную, ничего не происходит без решения самого человека.

Подборку по умолчанию собирает без ошибок и без единого обращения в
интернет встроенный расчётный механизм: он никогда не предложит курс,
который человек уже прошёл, или программу, недоступную для его должности.
По желанию к работе можно подключить языковую модель — она лишь
переупорядочивает уже отобранные программы и пишет приглашающий текст,
добавить или подменить программу она не может. Три группы моделей
(российская, зарубежная, локальная) измерены на задаче продукта;
результаты — в `output/сравнение-групп.xlsx`.

## Что нужно для запуска

Python 3.10+. (В офлайн-поставке заказчику Python и все библиотеки лежат
внутри, в папке `runtime`; в публичном репозитории её нет.) Интернет
нужен только в том случае, если вы решите включить языковую модель
(российскую или зарубежную) — сам расчёт трека работает офлайн.

## Как запустить

1. Распакуйте архив в любую папку — имя папки роли не играет.
2. Запустите `START.bat` (Windows) двойным щелчком, либо `start.sh` в
   терминале (macOS/Linux).
3. В открывшемся меню пункты **1–3** проверяют готовность соответствующей
   группы моделей (российской, зарубежной или локальной) перед запуском,
   пункт **4** запускает продукт без языковой модели (только расчёт; проверка
   данных при этом остаётся), а **5** только проверяет готовность, не открывая
   веб-интерфейс. Подборка при этом
   всегда строится расчётным механизмом; какая языковая модель (если
   она вообще настроена) будет её переупорядочивать, определяет
   администратор в `config.yaml` — подробности в
   `docs/инструкция-администратора.md`.
4. Продукт сам проверит, что данные в порядке, и откроет браузер с
   веб-интерфейсом «Мой путь развития». Если выбранная модель окажется
   недоступна, продукт молча покажет подборку без её участия — это не
   считается ошибкой.

## Что откроется

Сначала — экран выбора себя по должности или органу власти. После выбора:

- **Главная** — три самые подходящие программы с одной понятной фразой «почему
  рекомендовано», приглашение настроить рекомендации и ряд персональных
  электронных курсов. Отмеченная карточка сразу заменяется следующей.
- **Настройка рекомендаций** — пять коротких вопросов, около минуты. Не
  обязательна: подборка строится и без них.
- **Каталог программ** — все 161 программа с поиском и фильтрами.
- **Моё обучение** — ближайшие шаги, прогресс по направлениям и всё, что
  отмечено и пройдено.

Под каждой программой три действия: «хочу пройти», «не сейчас»,
«неактуально» — не больше пяти отметок в неделю на человека. Подробный путь по экранам — в
`docs/инструкция-пользователя.md`.

Чтобы остановить продукт, закройте окно `START.bat`/`start.sh`.

## Загрузка новых данных

Новая выгрузка обучения принимается без правки кода и без перезапуска:

1. Откройте раздел **«Данные»** (в шапке веб-интерфейса: пункт **«Для методиста»** → «Данные»; в основном меню слушателя его нет).
2. Перетащите файлы пакета: историю обучения и, если есть, реестр
   электронных курсов. Подходят Excel (`.xlsx`, `.xls`) и CSV; названия
   файлов и листов не важны — продукт определяет их по содержимому.
3. Проверьте экран **«Что я распознал»**: какой файл признан историей,
   какая колонка чему соответствует и с какой уверенностью. Если что-то
   определено неверно, выберите нужную колонку из списка.
4. Нажмите **«Применить эти данные»**. Прежние файлы сохраняются, их можно
   вернуть кнопкой «Вернуть предыдущую версию данных».

Проверить пакет из командной строки, ничего не меняя:
`python main.py --check-data --data-dir ПАПКА`
(без `--data-dir` проверяется папка `data`).

## Обновление каталога программ (буклет)

Новый буклет или каталог программ принимается там же, в разделе **«Данные»**, блок
«Каталог программ (буклет)»:

1. Выберите PDF-буклет «Линейка образовательных программ» или таблицу (Excel, CSV, Word):
   название, часы, форма обучения, категория слушателей, описание, треки.
2. Прочитайте отчёт **«Что изменится»**: сколько программ добавится, пропадёт, изменится.
3. **«Применить этот каталог»**. Прежний каталог сохраняется; кнопка «Вернуть предыдущий
   каталог программ» возвращает его. Поставляемый `catalog/programs.yaml` не перезаписывается:
   принятый каталог лежит в `output/programs.yaml`. При любой ошибке остаётся прежний каталог.

Из командной строки: `main.py --import-booklet ФАЙЛ` (только отчёт), с `--apply` — применить,
`main.py --revert-catalog` — откат.
